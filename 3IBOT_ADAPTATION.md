# 3ibot adaptation

This repository is a transparent fork of [Corey Haines's marketingskills](https://github.com/coreyhaines31/marketingskills).

It is maintained by **Shyam** under the 3ibot name. Corey Haines remains the original author of the upstream collection. The upstream MIT license and copyright notice in [LICENSE](LICENSE) are preserved.

3ibot-specific additions or changes should be documented in pull requests and must not be represented as Corey's original work. This fork uses a scheduled workflow that opens a review pull request when upstream changes are available; it never silently overwrites local modifications.
